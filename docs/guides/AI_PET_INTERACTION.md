# AIpet rotary interaction

- หมุนลูกกลิ้งซ้ายหรือขวา: AIpet หันตามพร้อมสีหน้าขี้เล่น
- หมุนเร็ว: เปลี่ยนเป็นสีหน้าตื่นเต้นพร้อมข้อความ `wheee!`
- หยุดหมุนประมาณ 1.5 วินาที: กลับไปมองรอบ ๆ ตามพฤติกรรมเดิม
- กดลูกกลิ้ง: ลูบ AIpet และแสดงปฏิกิริยาเหมือนเดิม
- กด Back: กลับหน้าเมนู

การหมุนตอบสนองภายในเครื่อง ไม่ต้องเชื่อมต่อ AI และไม่เริ่มบันทึกเสียงเพิ่ม ระหว่างรอ AI ประมวลผลยังหันตามลูกกลิ้งได้ โดยรักษาสีหน้าสถานะประมวลผลไว้

Host regression ใช้โค้ด InputController และฟังก์ชันตอบสนองการหมุนจริง ตรวจทิศทาง การหมุนเร็ว หมุนต่อเนื่อง 2,100 ครั้ง การหมุนระหว่างประมวลผล การกด และการกลับเมนู ต้องตรวจความรู้สึกในการหมุนและภาพเคลื่อนไหวบนบอร์ดจริงเพิ่มเติม
